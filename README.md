# 🍲 LexiSoup v2.0 — מערכת עתידנית לשינון מילים מובלע (Implicit Vocabulary Mastery)

> **פילוסופיית הליבה**: "החבאת ירקות במרק טעים" (Implicit Learning) — במקום כרטיסיות שינון משעממות וניחושים עיוורים, המערכת מספקת תהליך דו-שלבי חכם:
> 1. **שלב היכרות והכנה (Prep & Learn)**: מעבר על מילים, פירושיהן בעברית ומשפטי דוגמה מעשיים מהעולם האמיתי.
> 2. **ספרינט משחקי בדיקה (Test & Reinforce)**: סווייפ כרטיסיות, סימולטור צ'אט, ופצצת זמן לבחינת הזיכרון בתת-המודע.
> 3. **עוזר אישי AI (Conversational Mentor)**: שיחת יום-יום חופשית באנגלית שבה מנטור AI שוזר את המילים באלגנטיות ובודק את ההבנה שלך.

---

## 🚀 מה חדש בגרסה 2.0?

1. **שלב היכרות מקדים (Prep & Learn Mode)**:
   - מענה ישיר לתחושת ה"ניחוש": כעת ניתן לבחור סבב היכרות (5, 10 או 20 מילים) לפני שקופצים למשחקים.
   - לכל מילה מוצגים: הגייה קולית בלחיצה (🔊), פירוש מדויק בעברית, הגדרה באנגלית, ו-2 משפטי דוגמה עשירים המדגימים כיצד המילה משובצת בשיחה עסקית או טכנולוגית אמיתית.
   - בסיום שלב ההיכרות ניתן לקפוץ ישירות למשחק בדיקה ממוקד על המילים שנלמדו!

2. **עוזר אישי AI אינטראקטיבי (Alex • Lexi AI Mentor)**:
   - צ'אט חי ודינמי עם מנטור שפה מבוסס Gemini / Groq.
   - המנטור מנהל שיחת יום-יום קלילה וטבעית ("היי אושרי, מה שלומך היום? איך הפרויקטים?").
   - תוך כדי שיחה, המנטור שוזר מילים מתוך המאגר שלך (בפרט מילים שטעית בהן) ובודק אם אתה מבין אותן בהקשר.
   - השתמשת במילה נכון? תקבל מחמאה חמה ונקודות XP! שאלת "מה זה אומר?" — המנטור יסביר בעברית ובאנגלית בצורה ידידותית.

3. **לקסיקון מלא: כל המילים והפירושים במקום אחד (Full Lexicon Table)**:
   - כפתור ייעודי בלוח הבקרה ובניווט התחתון ("כל המילים 📚").
   - מעבר בלחיצה בין **תצוגת טבלה מפורטת** (מילה, תרגום, משפט דוגמה ומאסטרי) לבין **תצוגת כרטיסיות**.
   - כפתור הדפסה / ייצוא (🖨️) לצפייה מרוכזת בכל 300 המילים.

## 🧠 סקירת ארכיטקטורת ה-AI במערכת (Overall AI Architecture)

עבורך כמפתח Fullstack / Java / C# — הנה ההסבר המלא והתמציתי על מקומו של ה-AI במערכת:

### איפה ה-AI נמצא ומה תפקידו בתכלס?
המערכת מחולקת לשני עולמות:
1. **החלק הדטרמיניסטי (קוד מקומי - ללא AI)**:
   - חוקי המשחק, חישוב הניקוד, טיימרים, אלגוריתם ה-Spaced Repetition (חזרות מרווחות לפי SM-2), סינתיסייזר האודיו (Web Audio API) ושמירת הנתונים ב-LocalStorage/IndexedDB.
   - כל 300 המילים מ-Burlington English כבר שמורות מקומית ומייצרות משחקים באופן מיידי, כך שהמשחקים עובדים גם **100% אופליין ללא שום קריאת רשת**.

2. **החלק הגנרטיבי (שירותי ה-AI המופשטים דרך `AIService`)**:
   - **תפקיד 1: פיענוח וגזירת תרחישים מקבצים חדשים (File Ingestion)**:
     כשאתה מעלה קובץ PDF או TXT חדש, המערכת שולחת את הטקסט הגולמי ל-Gemini API עם הנחיית Schema (JSON structured output). ה-LLM מנתח את הטקסט, חולץ את המילים, מייצר תרגום עברי, וממציא אוטומטית משפטי סווייפ ותרחישי Slack עם חלל להשלמה.
   - **תפקיד 2: עוזר אישי ומנטור שיחה אינטראקטיבי (Conversational Tutor)**:
     בצ'אט העוזר האישי, ה-AI מקבל System Prompt מוגדר שבו מוזרקות מילות היעד שברצונך לתרגל. הוא מנהל דיאלוג דו-כיווני בזמן אמת, מנתח את התשובות שלך ומעריך אם הבנת את המילה.

### האם יש צורך בשינויי קוד מצידך?
**ממש לא! אין צורך לגעת בשורת קוד אחת.**
כל מה שנדרש כדי להפעיל את ה-AI החי הוא:
1. ללחוץ על סמל גלגל השיניים (⚙️) באפליקציה.
2. להדביק את מפתח ה-Gemini API שלך (שנוצר חינם ב-Google AI Studio).
3. ללחוץ "שמור הגדרות". המפתח נשמר בבטחה רק ב-LocalStorage של הדפדפן שלך.
*(אם אין לך מפתח זמין כרגע, המערכת כוללת מנוע סימולציה מקומי `LocalRuleProvider` המאפשר לבדוק את הצ'אט והעלאת הקבצים גם ללא מפתח חיצוני!)*

## 💾 שמירת נתונים ועדכוני Git (Data Persistence & GitHub Pages)

### "האם עדכון הקוד ב-Git ישמור על הנתונים וההתקדמות שלי?"
**כן, ב-100%!**

- **איפה הנתונים נשמרים?** כל ההתקדמות שלך (מילים שנלמדו, טעויות, רמת מאסטרי, נקודות XP ומפתח ה-API) נשמרים ב-**IndexedDB** וב-**LocalStorage** של הדפדפן תחת ה-Origin של הדומיין שלך (למשל: `https://yourusername.github.io`).
- **מה קורה כשדוחפים עדכון ל-Git?** הקוד ב-Git (HTML, CSS, JS) מתעדכן בשרת של GitHub Pages, אך **אחסון הדפדפן המקומי שלך אינו נמחק**. ברגע שתרענן את העמוד לאחר ה-push, האפליקציה החדשה תטען את הנתונים הקיימים ישירות מהדפדפן שלך בצורה שקופה לחלוטין.

כדי לעדכן את האתר הציבורי שלך ב-GitHub Pages עם הגרסה החדשה:

1. הורד את קובץ ה-ZIP המעודכן:
   **[LexiSoup - Vocabulary Mastery SPA.zip](https://drive.google.com/file/d/1nYo9mQ7V81mtHM5pEk79C4iamFKIEFoA/view?usp=drivesdk)**
2. חלץ את הקבצים ודרוס/החלף את הקבצים הקודמים בתיקיית המאגר שלך במחשב.
3. בטרמינל בתוך התיקייה, הרץ:
   ```bash
   git add .
   git commit -m "feat: add prep mode, AI conversational tutor, and full lexicon table"
   git push origin main
   ```
4. המתן כ-30 שניות עד דקה, רענן את האתר ב-GitHub Pages (מומלץ לבצע Hard Refresh עם `Ctrl+F5` או `Cmd+Shift+R` לניקוי Cache).
5. **סיימת! המערכת המעודכנת באוויר עם כל הפיצ'רים החדשים.**
